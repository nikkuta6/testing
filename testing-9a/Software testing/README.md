# Учебный компилятор и стековая виртуальная машина

Проект разбирает небольшой императивный язык, сразу генерирует стековый
байт-код и исполняет его на виртуальной машине. AST и отдельный токенайзер
намеренно не используются: это однопроходный учебный компилятор.

## Структура

```text
by.pranovich.testing
├── compiler   — внешний фасад Compiler и описание SyntaxError
├── parser     — рекурсивный спуск и проверка синтаксиса
├── bytecode   — инструкции, опкоды, Program и CodeGenerator
├── runtime    — стековая VirtualMachine
└── Main       — минимальный пример запуска
```

Поток выполнения:

```text
исходный текст → Compiler → RecursiveDescentParser → Program → VirtualMachine
```

## Поддерживаемый синтаксис

```text
int x = 1;
float y = 2.5;

int values[3];
int initialized = [1, 5, 2];
values[0] = initialized[1];
int squared = initialized[1] ^ 2;
int cubed = 2 ^ 3;

if x < 5 && y <> 0 {
    print max(x, initialized[2]);
} else {
    print 0;
}

while x < 10 {
    x = x + 1;
}
```

Встроенные функции: `sin`, `cos` (`cod` оставлен как совместимый псевдоним),
`tg`, `ctg`, `abs`, `max`, `min`. Оператор «не равно» записывается как `<>`.

Массивы одномерные. Размер задаётся числом или выражением, а инициализатор
может как задавать размер, так и дополнять уже заданный:

```text
int a[3];                  // массив из трёх нулей
int b[] = [1, 2, 3];       // размер берётся из инициализатора
int c[4] = [1, 2];         // размер 4, оставшиеся элементы — нули
int n = 3; int d[n];       // размер-выражение
int e = [1, 5, 2];         // краткая форма без размера
a[0] = b[1] + d[2];
print e[0];
print b == e;              // 0: сравнение целиком, нужна та же длина и те же элементы
print b <> e;              // 1
print c;                   // [1, 2, 0, 0]
```

Массив сравнивается только с массивом через `==` или `<>`; результат — `1` или `0`,
его можно использовать в `if`, `while`, `&&`, `||`. `print a;` под капотом вызывает
строковое представление массива; явная форма `print a.toString();` также поддерживается.
Элементы печатаются в формате типа массива (`[1, 2]` для `int`, `[1.0, 2.0]` для
`float`).

Индекс обязан быть целым и находиться в границах массива — иначе при
выполнении возникает ошибка.

Приоритет операторов (от высшего к низшему):

```text
! (факториал) → ^ → унарные + - → * / → + - → < > <= >= → == <> → && → ||
```

Оператор `^` — возведение в степень. Он правоассоциативен (`2 ^ 3 ^ 2`
вычисляется как `2 ^ (3 ^ 2) = 512`) и связывает сильнее унарного минуса
(`-2 ^ 2 = -(2 ^ 2) = -4`, а `(-2) ^ 2 = 4`). Показатель степени может быть
унарным выражением: `2 ^ -1 = 0.5`.

## Проверка

```shell
mvn test
```

Все тесты запускаются через единый сьют `by.pranovich.testing.AllTests`
(`src/test/java/by/pranovich/testing/AllTests.java`). Он автоматически находит
тестовые классы в пакете `by.pranovich.testing` и его подпакетах, поэтому новый
тест достаточно просто добавить в проект — регистрировать его в сьюте не нужно.

Все новые сценарии находятся в параметризованных тестах массивов, встроенных
функций и логических выражений.
