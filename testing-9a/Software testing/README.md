# Учебный компилятор и стековая виртуальная машина

Проект разбирает небольшой императивный язык, сразу генерирует стековый
байт-код и исполняет его на виртуальной машине. AST и отдельный токенайзер
намеренно не используются: это однопроходный учебный компилятор.

## Структура

```text
by.pranovich.testing
├── compiler   — внешний фасад Compiler и описание SyntaxError
├── parser     — рекурсивный спуск и проверка синтаксиса
├── bytecode   — инструкции, опкоды, Program и CodeGenerator
├── runtime    — стековая VirtualMachine
└── Main       — минимальный пример запуска
```

Поток выполнения:

```text
исходный текст → Compiler → RecursiveDescentParser → Program → VirtualMachine
```

## Поддерживаемый синтаксис

```text
int x = 1;
float y = 2.5;

int values[3];
int initialized = [1, 5, 2];
values[0] = initialized[1];
int squared = initialized[1] ^ 2;
int cubed = 2 ^ 3;

if x < 5 && y <> 0 {
    print max(x, initialized[2]);
} else {
    print 0;
}

while x < 10 {
    x = x + 1;
}
```

Встроенные функции: `sin`, `cos` (`cod` оставлен как совместимый псевдоним),
`tg`, `ctg`, `abs`, `max`, `min`. Оператор «не равно» записывается как `<>`.

Приоритет операторов (от высшего к низшему):

```text
! (факториал) → ^ → унарные + - → * / → + - → < > <= >= → == <> → && → ||
```

Оператор `^` — возведение в степень. Он правоассоциативен (`2 ^ 3 ^ 2`
вычисляется как `2 ^ (3 ^ 2) = 512`) и связывает сильнее унарного минуса
(`-2 ^ 2 = -(2 ^ 2) = -4`, а `(-2) ^ 2 = 4`). Показатель степени может быть
унарным выражением: `2 ^ -1 = 0.5`.
