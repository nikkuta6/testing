## 1. Типы данных
Язык поддерживает два основных числовых типа:
- int — целые числа.

## 2. Переменные и массивы

### Объявление переменных
Переменные объявляются с указанием типа:
 ` 
int x = 5;
float y = 3.14;
 ` 

### Работа с массивами
Массивы являются одномерными.

**Способы объявления:**
1. **С фиксированным размером:**
   int a[5]; — создает массив из 5 элементов (инициализированы нулями).
2. **С динамическим размером (через переменную):**
   int n = 10; int a[n];`n3. **С явной инициализацией (литералом):**
   int a = [1, 2, 3]; — размер определяется автоматически по количеству элементов.
4. **С фиксированным размером и инициализацией:**
   int a[3] = [1, 2]; — создаст массив размера 3, первые два элемента будут 1 и 2, последний — 0.

**Доступ к элементам:**
- Чтение: print(a[0]);`n- Запись: [1] = 10;`n- Индексы могут быть выражениями: [i + 1] = a[i] * 2;`n
## 3. Операторы и выражения

### Арифметические операторы
- +, -, *, / — стандартные операции.
- ^ — возведение в степень (например, x ^ 2).
- ! — вычисление факториала (например, [0]!).

### Логические и операторы сравнения
- ==, !=, >, <, >=, <= — сравнение.
- &&, || — логическое И и ИЛИ.
- ! — логическое НЕ.

### Приоритеты
Соблюдается стандартный математический приоритет операций.

## 6. Примеры программ

### Поиск максимума в массиве
 ` 
int a = [4, 9, 2, 9, 1]; 
int i = 1, best = 0;
while i < 5 { 
    if a[i] > a[best] { 
        best = i; 
    } 
    i = i + 1; 
}
print(best); 
print(a[best]);
 ` 

### Сортировка пузырьком
 ` 
int a = [5, 3, 4, 1, 2]; 
int i = 0, j = 0, t = 0;
while i < 4 { 
    j = 0;
    while j < 4 - i {
        if a[j] > a[j + 1] { 
            t = a[j]; 
            a[j] = a[j + 1]; 
            a[j + 1] = t; 
        }
        j = j + 1; 
    }
    i = i + 1; 
}
print(a[0]); print(a[1]); print(a[2]); print(a[3]); print(a[4]);
 ` 

## 7. Ошибки и ограничения
- **Compile Error**: возникает при синтаксических ошибках или использовании необъявленных переменных.
- **IndexOutOfBoundsException**: возникает при попытке доступа к элементу массива за пределами его размера.
- **IllegalStateException**: возникает, если массив был объявлен в ветке if, которая не была выполнена, но затем к нему обратились.
