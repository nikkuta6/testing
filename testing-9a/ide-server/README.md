# Веб-IDE (Ace Editor)

HTTP-сервер на встроенном в JDK `HttpServer`, без зависимостей. Компилятор и VM
берутся из исходников `../Software testing` (сам проект не меняется).

```shell
mvn compile exec:java            # нужен JDK 25, как и для Software testing
```

Открыть http://localhost:8080/ , запуск — кнопка ▶ или Ctrl+Enter.
Пошаговый режим — 🐞 или F5: F10 шаг по строке, F11 по инструкции, Shift+F10 назад, Shift+F5 стоп.
Текущая строка подсвечивается жёлтым (в коде и в байт-коде), строка с ошибкой — красным. Переменные текущего вызова функции
показываются в окне «Локальные переменные», глобальные — в окне «Глобальные переменные».
A− / A+ меняют размер шрифта только в окне кода.
Окно «Графика» показывает холст 400×300, на котором рисуют `color`, `point`, `line`, `rect`, `circle`, `clear`;
в пошаговом режиме видны только команды, выполненные до текущего шага. Кнопка ⛶ в заголовке окна открывает холст на весь экран, Esc — выход. Клик по холсту показывает в заголовке координаты точки (в единицах холста).
Если в программе объявлена `fun void onClick(int x, int y)`, клик вызывает её: после запуска по ▶ клики копятся, и при каждом
клике программа выполняется заново, а затем `onClick` вызывается для всех кликов по порядку, поэтому глобальные переменные
сохраняются между кликами. Новый запуск по ▶ сбрасывает клики. В пошаговом режиме клики не обрабатываются.

## API

`POST /api/run`, тело — исходный текст программы.

Ответ при синтаксической ошибке:

```json
{"syntaxError": {"message": "...", "line": 2, "position": 9}}
```

Иначе:

```json
{"bytecode": "0000  PUSH 1.0\n...", "output": "...", "canvas": ["color 255.0 0.0 0.0", "line 0.0 0.0 10.0 10.0"], "runtimeError": null,
 "variables": {"x": "2.5", "z": "3.0+4.0i", "a": "[1.0, 0.0-2.0i]"}, "locals": {}, "stack": []}
```

`variables` — глобальные переменные и массивы, `locals` — переменные и массивы текущего
вызова `fun` (на верхнем уровне пусто; при рекурсии — только самый внутренний кадр).
Значения — строки в формате VM: `2.0`, `3.0+4.0i`, `[1.0, 0.0-2.0i]`.
Ошибки выполнения (в том числе переполнение `int`) приходят текстом в `runtimeError`.

`POST /api/run?clicks=10,20;30,40` — то же самое, но после программы вызывается `onClick(10, 20)`, затем `onClick(30, 40)`
(не больше 1000 кликов). В ответе всегда есть `"onClick": true/false` — объявлен ли обработчик; без него клики игнорируются.

`POST /api/debug` — то же самое плюс `"lines"` (строка исходника для каждой инструкции, 0 — нет)
и `"steps"`: снимок VM перед каждой инструкцией `{"pc": 3, "out": 0, "cv": 0, "variables": {...}, "locals": {...}, "stack": [...]}`,
где `out` — длина уже напечатанного вывода, `cv` — число уже выполненных команд рисования. Записывается не больше 5000 шагов.

Программа выполняется не дольше 3 секунд, вывод ограничен 1 МБ.
