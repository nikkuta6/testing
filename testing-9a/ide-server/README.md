# Веб-IDE (Ace Editor)

HTTP-сервер на встроенном в JDK `HttpServer`, без зависимостей. Компилятор и VM
берутся из исходников `../Software testing` (сам проект не меняется).

```shell
mvn compile exec:java            # нужен JDK 25, как и для Software testing
```

Открыть http://localhost:8080/ , запуск — кнопка ▶ или Ctrl+Enter.
Пошаговый режим — 🐞 или F5: F10 шаг по строке, F11 по инструкции, Shift+F10 назад, Shift+F5 стоп.
Текущая строка подсвечивается жёлтым (в коде и в байт-коде), строка с ошибкой — красным. Переменные текущего вызова функции
показываются в окне «Локальные переменные», глобальные — в окне «Глобальные переменные».
A− / A+ меняют размер шрифта только в окне кода.

## API

`POST /api/run`, тело — исходный текст программы.

Ответ при синтаксической ошибке:

```json
{"syntaxError": {"message": "...", "line": 2, "position": 9}}
```

Иначе:

```json
{"bytecode": "0000  PUSH 1.0\n...", "output": "...", "runtimeError": null,
 "variables": {"x": "2.5", "z": "3.0+4.0i", "a": "[1.0, 0.0-2.0i]"}, "locals": {}, "stack": []}
```

`variables` — глобальные переменные и массивы, `locals` — переменные и массивы текущего
вызова `fun` (на верхнем уровне пусто; при рекурсии — только самый внутренний кадр).
Значения — строки в формате VM: `2.0`, `3.0+4.0i`, `[1.0, 0.0-2.0i]`.
Ошибки выполнения (в том числе переполнение `int`) приходят текстом в `runtimeError`.

`POST /api/debug` — то же самое плюс `"lines"` (строка исходника для каждой инструкции, 0 — нет)
и `"steps"`: снимок VM перед каждой инструкцией `{"pc": 3, "out": 0, "variables": {...}, "locals": {...}, "stack": [...]}`,
где `out` — длина уже напечатанного вывода. Записывается не больше 5000 шагов.

Программа выполняется не дольше 3 секунд, вывод ограничен 1 МБ.
