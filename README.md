компилируется в стековый байт-код (`RecursiveDescentParser` → `Program`)
и исполняется на `VirtualMachine`. Реализация — в [`Software testing`](testing-9a/Software%20testing),
веб-IDE для запуска программ — в [`ide-server`](testing-9a/ide-server).

## 1. Быстрый старт

```text
int n = 5;
int i = 1, f = 1;
while i <= n {
    f = f * i;
    i = i + 1;
}
print(n, f);        // 5 120
```

> `// ...` — настоящий комментарий языка (см. раздел [2](#2-лексика)). В этом
> документе после `//` обычно указан результат, который печатает строка.

Запуск из Java:

```java
Compiler compiler = new Compiler(source);
if (compiler.compile()) {
    new VirtualMachine().run(compiler.getProgram()); // ошибка выполнения — RuntimeException
} else {
    System.err.println(compiler.getSyntaxError()); // "Строка 2, позиция 9: ..."
}
```

Запуск в браузере — веб-IDE (нужен JDK 25):

```bash
cd testing-9a/ide-server && mvn compile exec:java
```

Затем открыть http://localhost:8080/ и нажать ▶ или Ctrl+Enter.
IDE показывает вывод, байт-код и значения переменных после выполнения
(глобальные и локальные переменные текущего вызова функции), а также умеет
выполнять программу по шагам.

## 2. Лексика

| Элемент | Правило | Примеры |
|---|---|---|
| Пробельные символы | Любые (пробел, табуляция, перевод строки) между лексемами игнорируются | |
| Идентификатор | Начинается с буквы или `_`, далее буквы, цифры, `_`. Буквы — любые Unicode, в том числе кириллица | `x`, `sum_2`, `_tmp`, `имя` |
| Целый литерал | Последовательность цифр, значение не больше `2^53 - 1` | `0`, `42` |
| Вещественный литерал | Есть точка или экспонента | `2.5`, `.5`, `3.`, `1e3`, `2E-1` |
| Мнимый литерал | Число, сразу за которым стоит `i`, а за `i` нет буквы, цифры или `_` | `4i`, `2.5i`, `1e2i`, `1i` |
| Комментарии | `// до конца строки` и `/* блочный, можно на несколько строк */`; допустимы везде, где допустим пробел | |
| Строки | **Не поддерживаются** | |

Знак числа — это унарный оператор, а не часть литерала: `-5` — это `-(5)`,
`-2i` — это `-(2i)`.

Суффикс `i` распознаётся только вплотную к числу: `2i` — мнимый литерал, а
`2 * i`, `2 *i` и `int i = 0; while i < 3 { ... }` работают с обычной переменной `i`.
Отдельной мнимой единицы без числа нет — пишите `1i`.

Ошибки компиляции в литералах:

- `1e400` — «Переполнение: число 1e400 слишком велико» (литерал-бесконечность);
- целый литерал (без точки и экспоненты) больше `2^53 - 1 = 9007199254740991`,
  например `9007199254740993`, — «Переполнение int: литерал больше 2^53 - 1»;
- неполная экспонента `2e`, `4ei` — «Некорректное число: 2e» (`4e`).

Незакрытый `/*` — ошибка компиляции «Незакрытый комментарий '/*'».

**Зарезервированные слова** (нельзя использовать как имена переменных, массивов,
функций и параметров):

```text
int  float  complex  void  if  else  while  print  fun  return
sin  cos  cod  tg  ctg  abs  max  min  _pi  _e  re  im  conj  arg
```

## 3. Типы и значения

| Тип | Описание |
|---|---|
| `int` | Целое число, по модулю не больше `2^53 - 1` |
| `float` | Число с плавающей точкой двойной точности |
| `complex` | Комплексное число: пара `float` (действительная и мнимая части) |
| `int[]`, `float[]`, `complex[]` | Одномерный массив чисел |
| `void` | Только тип результата функции: «ничего не возвращает» |

Логического типа нет: результат сравнений и логических операций — `int`
со значением `1` (истина) или `0` (ложь). В условиях `if`/`while` любое
ненулевое значение считается истиной.

Внутри виртуальной машины `int` и `float` хранятся как `double`, а `complex` —
как пара `double`. Тип выражения вычисляется компилятором; для `int` ВМ
проверяет, что значение целое и не выходит за `2^53 - 1` (тогда любое `int`
точно представимо в `double`), иначе — ошибка выполнения, а не неправильный
результат (см. раздел [6](#6-выражения-и-операторы)).

Правила вывода типа выражения:

- литерал с точкой или экспонентой — `float`, мнимый литерал — `complex`, иначе `int`;
- переменная — объявленный тип; элемент массива — тип массива;
- `+ - * / ^` — `complex`, если хотя бы один операнд `complex`; иначе `float`,
  если хотя бы один операнд `float`; иначе `int` (в том числе `7 / 2` и `2 ^ -1`);
- унарные `+`, `-` и факториал `x!` — тип операнда;
- сравнения, `== <> && ||`, логическое `!` — `int`;
- `max`, `min` — `float`, если хотя бы один аргумент `float`, иначе `int`;
- `abs` — тип аргумента для `int`/`float`, `float` для `complex`;
- `conj` — `complex`; `re`, `im`, `arg` и остальные встроенные функции — `float`;
- вызов пользовательской функции — её объявленный тип результата.

Продвижение типов при присваивании, инициализации, передаче аргумента и `return`:

- `int` → `float`, `int` → `complex`, `float` → `complex` — автоматически;
- `float` → `int` — допустимо при компиляции, но при выполнении значение должно
  быть целым, иначе «Потеря точности»;
- `complex` → `int`/`float` — ошибка компиляции «Значение complex нельзя сохранить
  в int» (используйте `re`, `im` или `abs`).

## 4. Переменные

Каждая переменная должна быть объявлена до использования.

```text
int x;                     // x = 0
float y = 2.5;
complex z = 3 + 4i;
int a = 1, b, c = a + 1;   // несколько имён через запятую
```

- Без инициализатора переменная равна `0` (`0.0+0.0i` для `complex`).
- Повторное объявление имени — ошибка компиляции (`Имя 'x' уже объявлено`).
- На верхнем уровне программы областей видимости нет: блоки `{ }` не создают
  новую область, имя, объявленное внутри блока, видно и после него.
  Собственная (локальная) область есть только у функций — см. раздел [8](#функции).
- Объявление внутри тела цикла допустимо: при каждой итерации оно просто
  повторно присваивает значение.

Присваивание:

```text
x = x + 1;
```

Присваивание — инструкция, а не выражение: `a = b = 1;` недопустимо.
Значение проверяется по правилам продвижения типов (раздел [3](#3-типы-и-значения)):
`int k = 2.9;` и `int h = 7 / 2;` — ошибка выполнения «Потеря точности».

## 5. Массивы

Массивы одномерные, элементы — числа типа массива, индексация с нуля.

### Объявление

```text
int a[3];                  // [0, 0, 0]
int b[] = [1, 2, 3];       // размер берётся из инициализатора
int c[4] = [1, 2];         // [1, 2, 0, 0] — хвост заполняется нулями
int n = 3; int d[n + 1];   // размер — произвольное выражение
int e = [1, 5, 2];         // краткая форма: тоже массив
float f[] = [];            // пустой массив
complex w[] = [1i, 2];     // [0.0+1.0i, 2.0+0.0i]
```

Массивы можно объявлять вперемешку с переменными: `int x = 1, m[2], k = [3, 4];`.

Размер вычисляется во время выполнения и должен быть целым неотрицательным
числом, иначе ошибка выполнения. Если значений в инициализаторе больше
размера (`int a[2] = [1, 2, 3];`) — тоже ошибка выполнения. Элементы
инициализатора и записываемые значения проверяются так же, как при
присваивании переменной: `int a[] = [0.5];` — «Потеря точности», `float a[] = [1i];` —
ошибка компиляции.

### Доступ к элементам

```text
a[0] = b[1] + d[2];
a[i + 1] = a[i] * 2;
```

Индекс должен быть целым (`a[0.5]` — ошибка) и лежать в диапазоне
`0 .. длина-1`; проверка выполняется во время работы программы.
Индекс и размер со значением `complex` — ошибка компиляции.

Имя массива без индекса нельзя использовать в арифметике, присваивать
целиком и передавать в функции: `a + 1`, `a = 5`, `f(a)` — ошибки компиляции.

Массив, объявленный в ветке, которая не выполнилась, проходит компиляцию, но
обращение к нему — ошибка выполнения «Массив 'a' ещё не создан».

### Сравнение массивов

```text
print(b == e);   // 0: нужна одинаковая длина и одинаковые элементы
print(b <> e);   // 1
```

Массив сравнивается только с массивом и только через `==` / `<>`.
Результат — `int` (`1`/`0`), его можно использовать в `if`, `while`, `&&`, `||`.
Элементы сравниваются как числа: `complex`-элемент `1.0+0.0i` равен `1`.

### Печать массива

```text
print(c);              // [1, 2, 0, 0]
print(f);              // [] ; для float-массива элементы печатаются как 1.0, 2.5
print(w);              // [0.0+1.0i, 2.0+0.0i]
```

## 6. Выражения и операторы

### Приоритет (от высшего к низшему)

| Уровень | Операторы | Ассоциативность | Смысл |
|---|---|---|---|
| 1 | `( )`, вызов функции, `a[i]` | — | Группировка, операнды |
| 2 | `x!` (постфиксный) | слева | Факториал |
| 3 | `^` | **справа** | Возведение в степень |
| 4 | унарные `+`, `-`, `!x` (префиксный) | — | Знак, логическое НЕ |
| 5 | `*`, `/` | слева | Умножение, деление |
| 6 | `+`, `-` | слева | Сложение, вычитание |
| 7 | `<`, `>`, `<=`, `>=` | слева | Сравнение |
| 8 | `==`, `<>` | слева | Равно, не равно |
| 9 | `&&` | слева | Логическое И |
| 10 | `\|\|` | слева | Логическое ИЛИ |

Остатка от деления (`%`) нет. «Не равно» записывается только как `<>`;
`!=` не поддерживается.

### Арифметика

Арифметика не возвращает неправильных значений: при переполнении, `NaN` и
делении на ноль возникает ошибка выполнения (`ArithmeticException`).

```text
float f = 10 ^ 400;   // Переполнение: результат выходит за пределы float (так же 1e308 * 10)
float g = (-8) ^ 0.5; // Недопустимая операция: результат не является числом
int a = 7 / 0;        // Деление на ноль (так же 1.0 / 0, ctg(0), 0 ^ -1)
int b = 7 / 2;        // Потеря точности: значение 3.5 нельзя сохранить в int
int c = 2 ^ 100;      // Переполнение int: ... по модулю больше 2^53 - 1
float m = 2 ^ 100;    // тоже Переполнение int: 2 ^ 100 — int-выражение
float n = 2.0 ^ 100;  // 1.2676506002282294E30
float h = 7 / 2;      // 3.5 — для float потеря точности не проверяется
```

- `/` — всегда вещественное деление, целочисленного деления нет: `7 / 2` даёт
  `3.5`, но выражение имеет тип `int`, поэтому сохранить его в `int` или
  напечатать нельзя («Потеря точности»). Дробный *промежуточный* результат
  допустим: `print(7 / 2 * 2);` печатает `7`, `float f = 2 ^ -1;` даёт `0.5`,
  а `print(2 ^ -1);` — «Потеря точности».
- Диапазон `int` проверяется для каждого промежуточного результата
  `int`-выражения (`+ - * / ^`, унарный `-`, факториал), даже если итог мал или
  сохраняется во `float`: `(2 ^ 60 + 1) - 2 ^ 60`, `9007199254740991 + 1` —
  «Переполнение int». `int ^ int` — это `int`, поэтому для больших степеней пишите
  `2.0 ^ 100`.
- Деление на ноль — ошибка выполнения «Деление на ноль» (и для `0 ^ -1`,
  `0.0 ^ -0.5`).
- `-0` нормализуется: `-0.0` не отличается от `0`, `0 == -0` — истина,
  `print(-0.0)` печатает `0.0`.
- `^` правоассоциативен и сильнее унарного минуса:
  `2 ^ 3 ^ 2 = 2 ^ 9 = 512`, `-2 ^ 2 = -4`, `(-2) ^ 2 = 4`.
  Показатель может быть унарным выражением: `2.0 ^ -1 = 0.5`.

### Факториал `x!`

Постфиксный `!` после операнда. Определён только для целых неотрицательных
значений, иначе ошибка выполнения: `2.5!`, `(-3)!` — «Факториал определён только
для целых неотрицательных чисел». Тип результата — тип операнда:
`5! = 120`, `0! = 1`, `3.0! = 6.0`. `int`-факториал проверяется на диапазон:
`18! = 6402373705728000`, а `19!` — «Переполнение int»; `19.0! = 1.21645100408832E17`,
`171.0!` — «Переполнение». Факториал связывает сильнее унарного минуса: `-3! = -6`.

### Логические операции

- `!x` — логическое НЕ: `1`, если `x == 0`, иначе `0`. После префиксного `!`
  должно идти имя, вызов или выражение в скобках: `!a`, `!(x > 1)`, но не `!5`.
- `&&`, `||` возвращают `1`/`0`. **Вычисление не сокращённое**: оба операнда
  вычисляются всегда.
- Сравнения можно сцеплять, но они вычисляются слева направо как обычные
  бинарные операции: `1 < 2 < 3` — это `(1 < 2) < 3`, то есть `1 < 3`, то есть `1`.

### Комплексные числа

```text
complex z = 3 + 4i;
print(z * conj(z));           // 25.0+0.0i
print(1 - 2i, conj(2i));      // 1.0-2.0i 0.0-2.0i
print(1i ^ 2);                // -1.0+0.0i
print(z / (1 - 2i));          // -1.0+2.0i
print(3 + 0i == 3, -z);       // 1 -3.0-4.0i
```

- Выражение имеет тип `complex`, если хотя бы один операнд — `complex`.
- Допустимы унарные `+`, `-`, бинарные `+ - * / ^`, `==` и `<>` (сравнение с
  вещественным числом: `3 + 0i == 3` — истина).
- Запрещены (ошибка компиляции «…: значение complex недопустимо»):
  `< > <= >=`, `&&`, `||`, `!`, факториал, условие `if`/`while`, индекс и
  размер массива, функции `sin`, `cos`, `cod`, `tg`, `ctg`, `max`, `min`.
- Возведение в целую степень выполняется умножением (поэтому `1i ^ 2` — ровно
  `-1.0+0.0i`), в остальных случаях — через полярную форму:
  `(-4 + 0i) ^ 0.5` — `1.2246467991473532E-16+2.0i`. При отрицательной целой
  степени сначала берётся обратное основание: `(2 + 0i) ^ -2000` — `0.0+0.0i`,
  `(2 + 0i) ^ 2000` — «Переполнение».
- Если оба операнда вещественные, работает вещественная арифметика:
  `(-8) ^ 0.5` — ошибка, а `(-8 + 0i) ^ 0.5` — комплексный корень.
- Деление масштабирует делитель, поэтому `z / z` даёт `1.0+0.0i` и для
  `z = 1e200 + 1e200i`, а `1 / (1e-200 + 1e-200i)` — `5.0E199-5.0E199i`.
  Деление на `0 + 0i` — «Деление на ноль».
- Переполнение или `NaN` в любой из частей — те же ошибки выполнения, что и для
  вещественных чисел.

## 7. Встроенные функции

| Функция | Аргументы | Результат | Тип результата |
|---|---|---|---|
| `sin(x)` | 1 | синус (радианы) | `float` |
| `cos(x)`, `cod(x)` | 1 | косинус; `cod` — совместимый псевдоним | `float` |
| `tg(x)` | 1 | тангенс | `float` |
| `ctg(x)` | 1 | котангенс `1 / tg(x)`; `ctg(0)` — «Деление на ноль» | `float` |
| `abs(x)` | 1 | модуль; для `complex` — модуль комплексного числа | тип аргумента, `float` для `complex` |
| `max(a, b, ...)` | ≥ 2 | максимум | `float`, если есть `float`-аргумент |
| `min(a, b, ...)` | ≥ 2 | минимум | `float`, если есть `float`-аргумент |
| `_pi()` | 0 | π = 3.141592653589793 | `float` |
| `_e()` | 0 | e = 2.718281828459045 | `float` |
| `re(z)` | 1 | действительная часть | `float` |
| `im(z)` | 1 | мнимая часть | `float` |
| `arg(z)` | 1 | аргумент (угол) в радианах, `(-π, π]` | `float` |
| `conj(z)` | 1 | сопряжённое число | `complex` |

```text
complex z = 3 + 4i;
print(abs(z), arg(1i));       // 5.0 1.5707963267948966
print(re(z), im(z));          // 3.0 4.0
print(re(5), im(5), conj(5)); // 5.0 0.0 5.0+0.0i
```

`re`, `im`, `arg`, `conj` принимают и вещественный аргумент (он считается
числом с нулевой мнимой частью). Функции `sin`, `cos`, `cod`, `tg`, `ctg`, `max`,
`min` от `complex` — ошибка компиляции.

Неверное число аргументов или неизвестное имя функции — ошибка компиляции.
Пользовательские функции объявляются через `fun` — см. раздел [8](#функции).

## 8. Инструкции

Программа — последовательность инструкций и объявлений функций. Простые
инструкции заканчиваются `;`.

| Инструкция | Синтаксис |
|---|---|
| Объявление | `int x = 1, a[3];` / `float y;` / `complex z = 1i;` |
| Присваивание | `x = выражение;` / `a[i] = выражение;` |
| Вывод | `print(выр, ...);` |
| Блок | `{ инструкции }` |
| Ветвление | `if условие { ... } else { ... }` |
| Цикл | `while условие { ... }` |
| Объявление функции | `fun тип имя(тип параметр, ...) { ... }` |
| Возврат | `return выражение;` / `return;` |
| Вызов функции | `имя(аргументы);` — результат отбрасывается |

### `if` / `else`

```text
if x > 0 {
    print(1);
} else if x < 0 {
    print(-1);
} else {
    print(0);
}
```

- Скобки вокруг условия не обязательны: `if (x > 0) { ... }` тоже работает,
  потому что это просто выражение в скобках.
- Фигурные скобки у тела **обязательны**: `if x print(x);` — ошибка.
- После `else` — либо блок, либо следующий `if`.

### `while`

```text
int i = 0;
while i < 10 {
    i = i + 1;
}
```

Условие проверяется перед каждой итерацией. Тело — обязательно блок.
Операторов `break`/`continue` и цикла `for` нет.

### Функции

```text
fun int add(int a, int b) {
    return a + b;
}
fun complex sq(complex z) { return z * z; }
fun void show(float x) { print(x); return; }
fun int fact(int n) { if n <= 1 { return 1; } return n * fact(n - 1); }
print(add(2, 3));             // 5
print(even(4));               // 1: функцию можно вызвать выше её объявления
show(1.5);                    // 1.5: вызов как инструкция
print(sq(1i), fact(10));      // -1.0+0.0i 3628800
fun int even(int n) { if n == 0 { return 1; } return 1 - even(n - 1); }
```

- Тип результата: `int`, `float`, `complex` или `void`; параметры только
  скалярные (`int`, `float`, `complex`). Массивы нельзя передавать в функцию и
  возвращать из неё.
- `fun` объявляется только на верхнем уровне (не внутри `if`, `while`, блока или
  другой функции). Тело не выполняется, когда программа «проходит мимо» объявления.
- Функцию можно вызывать до объявления и рекурсивно, в том числе взаимно.
  Глубина вызовов ограничена 10 000, дальше — «Переполнение стека вызовов».
- Вызов не-`void` функции как инструкции (`add(1, 1);`) допустим, результат
  отбрасывается. `void`-функция в выражении — ошибка компиляции.
- Параметры и объявленные в теле переменные и массивы — локальные, у каждого
  вызова свои. Из функции видны глобальные переменные и массивы, объявленные
  выше по тексту; их можно читать и изменять. Локальное имя (в том числе
  параметр) может затенять глобальное, но только если глобальное с этим именем
  в функции ещё не использовалось (`print(x); int x = 2;` в теле — ошибка компиляции).
- Если функцию вызвали раньше, чем выполнилось объявление глобального имени,
  которое она читает, это ошибка выполнения:
  `print(f()); int g = 5; fun int f() { return g; }` — «Переменная 'g' ещё не
  инициализирована», для массива — «Массив 'b' ещё не создан».
- Аргументы и `return выражение;` следуют правилам присваивания: `int`/`float` →
  `complex` можно, `complex` → `int`/`float` нельзя (ошибка компиляции),
  `int`-параметр или результат проверяется на потерю точности и переполнение
  при выполнении (`f(2.5)` для `int`-параметра — «Потеря точности»).
- `return;` — только в `void`-функции, `return выражение;` — только в не-`void`;
  `return` вне функции — ошибка компиляции. `void`-функция может закончиться без
  `return`, не-`void` — нет: «Функция 'f' завершилась без return» (ошибка выполнения).
- Имя функции не может совпадать с ключевым словом, встроенной функцией,
  переменной или массивом; повторное объявление функции или параметра — ошибка.

```text
int g = 10;
int arr[] = [1, 2, 3];
fun void bump() { g = g + 1; arr[0] = 7; }
fun int twice(int g) { return g * 2; }   // параметр g затеняет глобальную g
bump();
print(g, arr, twice(3));                 // 11 [7, 2, 3] 6
```

## 9. Вывод: `print`

```text
print(x);              // одно значение и перевод строки
print(i, sum, a);      // значения через пробел, в конце перевод строки
print();               // пустая строка
```

Формат зависит от *статического типа* выражения:

| Тип | Как печатается | Пример |
|---|---|---|
| `int` | целое без дробной части; дробное значение — ошибка «Потеря точности» | `3`, `-2`, `120` |
| `float` | как Java `double` | `3.5`, `3.0`, `1000.0`, `1.0E20` |
| `complex` | `re+imi` или `re-|im|i`, части — как `float` | `3.0+4.0i`, `0.0-2.0i` |
| массив | `[e1, e2, ...]` в формате типа массива | `[1, 2]`, `[1.0, 2.5]`, `[0.0+1.0i]` |

`NaN` и `Infinity` напечатать нельзя: такие значения не возникают, вместо них
бывает ошибка выполнения.

## 10. Ошибки

### Ошибки компиляции

`compile()` возвращает `false`, а `getSyntaxError()` — объект `SyntaxError`
с сообщением, номером строки и позиции (с единицы):

```text
Строка 1, позиция 11: Ожидался символ ';', но найдено: 'p'
```

Сообщения (вместо `x`, `a`, `f`, `int` и т. п. подставляются имена и типы из программы):

| Сообщение | Причина |
|---|---|
| **Синтаксис** | |
| `Ожидался символ ';', но найдено: 'p'` | пропущен символ |
| `Ожидалось начало инструкции, но найдено: '...'` | инструкция начинается не с имени, ключевого слова или `{` |
| `Ожидался операнд, но достигнут конец ввода` | выражение оборвалось |
| `Ожидался операнд (имя, число или скобка), но найдено: '...'` | на месте операнда другой символ |
| `После '!' ожидалось имя или выражение в скобках, но найдено: '5'` | `!5` |
| `Ожидался идентификатор, но найдено: 'sin'` | зарезервированное слово как имя |
| `Ожидалась '}'` | незакрытый блок |
| `'else' без предшествующего 'if'` | лишний `else` |
| `После 'else' ожидался блок '{' или 'if'` | `else print(1);` |
| `Незакрытый комментарий '/*'` | нет `*/` |
| **Литералы** | |
| `Переполнение: число 1e400 слишком велико` | литерал-бесконечность |
| `Переполнение int: литерал больше 2^53 - 1` | `9007199254740993` |
| `Некорректное число: 2e` | неполная экспонента (`2e`, `4ei`) |
| **Переменные и массивы** | |
| `Переменная 'x' не объявлена` | использование до объявления |
| `Имя 'x' уже объявлено` | повторное объявление |
| `Ожидался оператор '=' после 'x'` | `x;`, `x + 1;` |
| `Массив 'a' не объявлен` | `a[0]` для необъявленного массива |
| `Для чтения элемента массива 'a' нужен индекс` | массив без `[i]` в выражении (в том числе как аргумент функции) |
| `Для присваивания элементу массива 'a' нужен индекс` | `a = 5;` |
| `Ожидался оператор '=' после элемента массива 'a'` | `a[0];` |
| `Для массива без размера ожидался инициализатор '[...]'` | `int a[];` |
| `Массив 'a' можно сравнивать только с массивом` | `a == x` для числа `x` |
| **Встроенные функции** | |
| `Неизвестная встроенная функция 'h'` | вызов в выражении необъявленной функции |
| `Функция 'sin' принимает ровно один аргумент` | неверное число аргументов (`sin cos cod tg ctg abs re im conj arg`) |
| `Функция 'max' принимает не менее двух аргументов` | `max(1)`, `min(1)` |
| `Функция '_pi' не принимает аргументов` | `_pi(1)`, `_e(1)` |
| **complex** | |
| `Значение complex нельзя сохранить в int` | `complex` в `int`/`float` (переменная, элемент, аргумент, `return`) |
| `Оператор '<': значение complex недопустимо` | также `'>'`, `'<='`, `'>='`, `'&&'`, `'\|\|'`, `'!'` |
| `Факториал: значение complex недопустимо` | `1i!` |
| `Условие 'if': значение complex недопустимо` | также `Условие 'while'` |
| `Индекс массива: значение complex недопустимо` | также `Размер массива` |
| `Функция 'sin': значение complex недопустимо` | также `cos cod tg ctg max min` |
| **Пользовательские функции** | |
| `Ожидался тип результата функции (int, float, complex или void), но найдено: '...'` | `fun f() { }` |
| `Ожидался тип параметра (int, float или complex), но найдено: '...'` | `fun int f(x) { ... }` |
| `Параметр 'a' уже объявлен` | два параметра с одним именем |
| `Функция 'f' уже объявлена` | повторное объявление функции |
| `Имя 'f' уже объявлено как функция` | переменная или массив с именем функции |
| `Функцию можно объявить только на верхнем уровне программы` | `fun` внутри блока, `if`, `while` или функции |
| `Функция 'g' не объявлена` | вызов-инструкция `g();` необъявленной функции |
| `Функция 'f' принимает аргументов: 1, передано: 2` | неверное число аргументов |
| `Функция 'f' объявлена как void и не может быть частью выражения` | `int x = f();` для `void f` |
| `'return' вне функции` | `return` на верхнем уровне |
| `Функция 'f' объявлена как void и не возвращает значение` | `return 1;` в `void`-функции |
| `Функция 'f' должна вернуть значение int` | `return;` в не-`void` функции |
| `Имя 'x' уже использовано в функции как глобальное` | локальное объявление после использования глобального с тем же именем |

### Ошибки выполнения

Виртуальная машина бросает Java-исключение и останавливает программу
(в веб-IDE его текст попадает в поле `runtimeError`):

| Ситуация | Исключение и сообщение |
|---|---|
| Результат бесконечен | `ArithmeticException`: `Переполнение: результат выходит за пределы float` |
| Результат `NaN` | `ArithmeticException`: `Недопустимая операция: результат не является числом` |
| Деление на ноль (`/`, `ctg`, `0 ^ -1`, на `0 + 0i`) | `ArithmeticException`: `Деление на ноль` |
| Дробное значение в `int` (сохранение, печать, аргумент, `return`) | `ArithmeticException`: `Потеря точности: значение 3.5 нельзя сохранить в int` |
| `int` по модулю больше `2^53 - 1` (в том числе промежуточный) | `ArithmeticException`: `Переполнение int: значение 1.2676506002282294E30 по модулю больше 2^53 - 1` |
| Факториал от нецелого или отрицательного | `ArithmeticException`: `Факториал определён только для целых неотрицательных чисел: 2.5` |
| Индекс вне границ | `IndexOutOfBoundsException`: `Индекс 2 вне границ массива 'a' длины 2` |
| Нецелый индекс | `IndexOutOfBoundsException`: `Индекс массива 'a' должен быть целым: 0.5` |
| Размер массива отрицательный или нецелый | `IllegalArgumentException`: `Размер массива должен быть целым неотрицательным числом: -1.0` |
| Значений в инициализаторе больше размера | `IllegalArgumentException`: `Слишком много значений для массива 'a': 3, размер 2` |
| Массив объявлен в невыполненной ветке или функция читает ещё не созданный глобальный массив | `IllegalStateException`: `Массив 'a' ещё не создан` |
| Функция читает глобальную переменную до её объявления | `IllegalStateException`: `Переменная 'g' ещё не инициализирована` |
| Не-`void` функция дошла до конца тела | `IllegalStateException`: `Функция 'f' завершилась без return` |
| Глубина вызовов больше 10 000 | `IllegalStateException`: `Переполнение стека вызовов: глубина больше 10000` |

## 11. Грамматика (EBNF)

```ebnf
program        = { statement | function } ;

statement      = declaration | assignment | callStatement | print
               | if | while | return | block ;
block          = "{" { statement } "}" ;

declaration    = type declarator { "," declarator } ";" ;
type           = "int" | "float" | "complex" ;
declarator     = IDENT
               | IDENT "=" expression
               | IDENT "=" arrayLiteral
               | IDENT "[" [ expression ] "]" [ "=" arrayLiteral ] ;
               (* "[]" без размера требует инициализатор *)
arrayLiteral   = "[" [ expression { "," expression } ] "]" ;

assignment     = IDENT [ "[" expression "]" ] "=" expression ";" ;

function       = "fun" ( type | "void" ) IDENT
                 "(" [ parameter { "," parameter } ] ")" block ;
               (* только на верхнем уровне программы *)
parameter      = type IDENT ;
return         = "return" [ expression ] ";" ;   (* только внутри функции *)
callStatement  = FUN_IDENT "(" [ arguments ] ")" ";" ;
arguments      = expression { "," expression } ;

if             = "if" expression block [ "else" ( block | if ) ] ;
while          = "while" expression block ;

print          = "print" "(" [ printArg { "," printArg } ] ")" ";" ;
printArg       = ARRAY_IDENT | expression ;

expression     = or ;
or             = and { "||" and } ;
and            = equality { "&&" equality } ;
equality       = ( ARRAY_IDENT ( "==" | "<>" ) ARRAY_IDENT | comparison )
                 { ( "==" | "<>" ) comparison } ;
comparison     = additive { ( "<" | ">" | "<=" | ">=" ) additive } ;
additive       = multiplicative { ( "+" | "-" ) multiplicative } ;
multiplicative = unary { ( "*" | "/" ) unary } ;
unary          = "+" power
               | "-" power
               | "!" operand [ "^" unary ]
               | power ;
power          = operand [ "^" unary ] ;
operand        = primary { "!" } ;
primary        = "(" expression ")"
               | FUN_IDENT "(" [ arguments ] ")"     (* пользовательская функция *)
               | BUILTIN "(" [ arguments ] ")"       (* встроенная функция *)
               | IDENT "[" expression "]"
               | IDENT
               | NUMBER
               | IMAGINARY ;

IDENT          = ( letter | "_" ) { letter | digit | "_" } ;
NUMBER         = ( digits [ "." { digit } ] | "." digits ) [ ( "e" | "E" ) [ "+" | "-" ] digits ] ;
IMAGINARY      = NUMBER "i" ;   (* без пробела; за "i" не идёт буква, цифра или "_" *)
COMMENT        = "//" { любой символ кроме перевода строки }
               | "/*" { любой символ } "*/" ;   (* пропускается как пробел *)
```

`FUN_IDENT` — имя функции, объявленной через `fun` где угодно в программе
(сигнатуры собираются до основного прохода), `BUILTIN` — имя встроенной функции.

## 12. Байт-код и виртуальная машина

Компилятор генерирует плоский список инструкций; ВМ исполняет их со
стеком значений (`double` для `int`/`float`, `Complex` для `complex`),
таблицами глобальных переменных и массивов и стеком кадров вызова функций
(в каждом кадре — свои локальные переменные и массивы). В конце программы
всегда стоит `HALT`. Байт-код виден в веб-IDE.

| Опкод | Операнд | Действие |
|---|---|---|
| `PUSH` | число или комплексное число | положить константу в стек (`PUSH 3.0`, `PUSH 0.0+4.0i`) |
| `LOAD` | имя | прочитать переменную в стек |
| `STORE` | `[имя, тип]` | снять значение, проверить по типу цели и записать (`STORE [x, int]`) |
| `ARRAY_NEW` | `имя 0 sized тип` | снять размер, создать массив из нулей |
| `ARRAY_INIT` | `имя кол-во [sized] тип` | снять элементы (и размер, если `sized`), создать массив |
| `ARRAY_LOAD` | имя | снять индекс, положить элемент |
| `ARRAY_STORE` | `[имя, тип]` | снять значение и индекс, записать элемент |
| `ARRAY_EQ` | `[имя1, имя2]` | положить `1`/`0` — равны ли массивы |
| `ARRAY_PRINT` | `[имя, тип]` | напечатать массив |
| `ADD SUB MUL DIV POW` | тип результата | арифметика над двумя верхними значениями; для `int` проверяется диапазон (`ADD int`, `POW complex`) |
| `LT GT LE GE EQ NE` | — | сравнение, результат `1`/`0` |
| `AND OR` | — | логика, результат `1`/`0` |
| `NEG` / `FACT` | тип результата | унарный минус / факториал (`NEG int`, `FACT float`) |
| `NOT` | — | логическое НЕ |
| `CALL` | `имя/кол-во` | вызвать встроенную функцию (`CALL max/2`) |
| `CALL_FUN` | адрес | создать кадр вызова и перейти на `ENTER` функции |
| `ENTER` | `[локальные имена]` | начало тела функции: список локальных имён кадра |
| `RET` | тип | снять кадр и вернуться; значение проверяется по типу (`void` — без значения) |
| `NO_RETURN` | имя функции | конец тела не-`void` функции: ошибка «завершилась без return» |
| `POP` | — | снять значение (результат вызова-инструкции) |
| `JMP` | адрес | безусловный переход |
| `JZ` | адрес | снять значение; перейти, если оно `0` |
| `PRINT` | тип | снять и напечатать значение |
| `PRINT_SPACE` / `PRINT_NEWLINE` | — | напечатать пробел / перевод строки |
| `HALT` | — | остановка |

Пример: `int i = 0; while i < 3 { i = i + 1; }` компилируется в
(`Program.disassemble()`):

```text
0000  PUSH 0.0
0001  STORE [i, int]
0002  LOAD i
0003  PUSH 3.0
0004  LT
0005  JZ 11
0006  LOAD i
0007  PUSH 1.0
0008  ADD int
0009  STORE [i, int]
0010  JMP 2
0011  HALT
```

Тело функции перепрыгивается `JMP`, начинается с `ENTER`, за которым параметры
снимаются со стека через `STORE` (последний аргумент — на вершине).
`fun int sq(int x) { return x * x; } print(sq(3)); sq(2);`:

```text
0000  JMP 8
0001  ENTER [x]
0002  STORE [x, int]
0003  LOAD x
0004  LOAD x
0005  MUL int
0006  RET int
0007  NO_RETURN sq
0008  PUSH 3.0
0009  CALL_FUN 1
0010  PRINT int
0011  PRINT_NEWLINE
0012  PUSH 2.0
0013  CALL_FUN 1
0014  POP
0015  HALT
```

## 13. Особенности и известные ограничения

1. **Нет целочисленного деления и приведения типов.** `/` всегда вещественное:
   `int x = 7 / 2;` — ошибка «Потеря точности», `float x = 7 / 2;` — `3.5`.
   Функций округления (`floor`, `round`) и `%` нет.
2. **`int ^ int` — это `int`.** `float f = 2 ^ 100;` — «Переполнение int»,
   нужно писать `2.0 ^ 100`. `print(2 ^ -1)` — «Потеря точности», а
   `float x = 2 ^ -1;` — `0.5`.
3. **Тип факториала — тип операнда.** `19!` — «Переполнение int», `19.0!` —
   `1.21645100408832E17`.
4. **Промежуточные `int`-результаты тоже проверяются** на диапазон `2^53 - 1`:
   `(2 ^ 60 + 1) - 2 ^ 60` — ошибка, даже если итог мал.
5. Арифметика не даёт `Infinity`/`NaN` и не делит на ноль — вместо этого ошибка
   выполнения; `-0.0` нормализуется в `0.0`.
6. У `complex` нет порядка и истинности: его нельзя сравнивать через `< >`,
   использовать в условиях, логике, индексах и тригонометрии.
7. Функции: только на верхнем уровне, без вложенных функций и замыканий;
   массивы нельзя передавать в функции и возвращать из них; глубина рекурсии —
   не больше 10 000 вызовов. Из функции видны только глобальные имена,
   объявленные выше по тексту.
8. Нет строк, методов (в том числе `a.toString()`), `%`, `!=`, `for`, `break`,
   `continue`, многомерных массивов, ввода данных, приведения типов,
   многопоточности.
9. `&&` и `||` всегда вычисляют оба операнда.
10. На верхнем уровне блоки не создают область видимости; локальная область есть
    только у функций.
11. В веб-IDE программа выполняется не дольше 3 секунд, вывод ограничен 1 МБ.

## 14. Примеры программ

### Наибольший общий делитель (вычитанием)

```text
int a = 84, b = 36;
while a <> b {
    if a > b { a = a - b; } else { b = b - a; }
}
print(a);                      // 12
```

### Сумма и максимум массива

```text
int v[] = [4, 9, 1, 7];
int i = 0, s = 0, m = v[0];
while i < 4 {
    s = s + v[i];
    m = max(m, v[i]);
    i = i + 1;
}
print(s, m);                   // 21 9
```

### Пузырьковая сортировка

```text
int a[] = [5, 2, 8, 1, 9];
int n = 5, i = 0, j, t;
while i < n - 1 {
    j = 0;
    while j < n - 1 - i {
        if a[j] > a[j + 1] {
            t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
        }
        j = j + 1;
    }
    i = i + 1;
}
print(a);                      // [1, 2, 5, 8, 9]
```

### Ряд Тейлора для sin(x)

```text
float x = _pi() / 6, term = x, sum = 0, x2 = x * x;
int i = 0;
while i < 10 {
    sum = sum + term;
    i = i + 1;
    term = -term * x2 / (2 * i * (2 * i + 1));
}
print(sum, sin(x));            // 0.49999999999999994 0.49999999999999994
```

### Рекурсивная функция: числа Фибоначчи

```text
fun int fib(int n) {
    if n < 2 { return n; }
    return fib(n - 1) + fib(n - 2);
}
print(fib(10), fib(20));       // 55 6765
```

### Комплексные числа: степени 1 + i

```text
complex z = 1 + 1i, p = 1;
int k = 1;
while k <= 4 {
    p = p * z;
    print(k, p, abs(p));
    k = k + 1;
}
print(z ^ 8, z / conj(z));     // 16.0+0.0i 0.0+1.0i
```
